📈 Zerodha Clone – Trading Platform UI

A Zerodha-inspired trading platform clone built to practice full-stack development, authentication flow, dashboard routing, and real-world fintech UI structure.
This project focuses on clean UI, proper routing, and user experience similar to Zerodha.

🚀 Features  -- 

🔐 User Authentication (Login / Signup)

📊 Dashboard UI (Holdings, Positions, Funds)

📈 Market Watch Interface

🔁 Correct routing after login

🧭 Navigation similar to Zerodha Kite

💻 Responsive design 

⚡ Fast & lightweight frontend

🛠️ Tech Stack  --

Frontend :

HTML

CSS

JavaScript

React.js 

Backend :

Node.js

Express.js

Database :

MongoDB 

Deployment :

Render / Vercel / Netlify 

⚙️ Installation & Setup :
1️⃣ Clone the repo
git clone https://github.com/RaghvendraPatel/zerodha-clone.git

2️⃣ Install dependencies :
npm install

3️⃣ Run project :
npm start

🎯 Purpose of this Project

This project was built to:

Understand real-world dashboard routing

Practice authentication flows

Build confidence in full-stack development

Learn how fintech platforms are structured

Improve UI/UX thinking
